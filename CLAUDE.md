# MultiTracker

Перед изменением интерфейса прочитайте @DESIGN.md целиком.
Используйте описанные там цвета, типографику, отступы и состояния компонентов.
Если меняется дизайн, обновляйте документ вместе с реализацией.

Это статический макет: сохраняйте разделы, RU/EN и демонстрационные сценарии.
Перед завершением выполните `npm run check` и проверку изменённых экранов
через agent-browser. Валидация DESIGN.md не заменяет просмотр интерфейса.
