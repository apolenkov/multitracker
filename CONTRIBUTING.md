# Как участвовать

Исходники проекта: [apolenkov/multitracker](https://github.com/apolenkov/multitracker).
Ошибки и предложения обсуждаются в [Issues](https://github.com/apolenkov/multitracker/issues),
изменения — в запросах на включение кода. Воспроизводите проблему на вымышленных
данных; сведения об уязвимостях отправляйте по [SECURITY.md](SECURITY.md).

1. Прочитайте [README](README.md), [DESIGN](DESIGN.md), [AGENTS](AGENTS.md),
   [текущие требования](openspec/changes/complete-prototype/specs/readiness/spec.md)
   и [дорожную карту](docs/plans/2026-09-30-roadmap.md).
2. Установите Node из `.nvmrc`, Gitleaks 8.30.1 и зависимости через `npm ci`.
3. Дорабатывайте существующий модуль на его языке; новый код — TypeScript.
   Сохраняйте неизменяемые входные данные и существующую простую структуру.
4. Выполните `npm run format` и `npm run check`. Для изменённого поведения
   добавьте небольшую проверку наблюдаемого результата и обновите документы.
   При изменении интерфейса выполните отдельный `npm run test:ui` и ручные
   затронутые сценарии: RU/EN, 375/1440 px, ошибки, отмена, клавиатура и фокус.
5. В запросе на изменение укажите проблему, итоговое поведение, точные результаты
   проверок и ограничения. Незапущенная проверка не считается пройденной.

Авторский код, тесты, конфигурация и служебные программы: файл ≤300 строк,
функция ≤50, обычная и когнитивная сложность ≤10. Пустые строки, комментарии
и JSX считаются. `let`, мутации объектов/массивов, отключения правил и
небезопасные утверждения типов запрещены; длинная строка не заменяет организацию кода.

Используйте только вымышленные данные. Не добавляйте реальные ключи, выписки,
удалённые шрифты, аналитику или сетевые интеграции в макет. Проверяйте лицензии.
Сырые локальные снимки и журналы из `docs/audits/` и `docs/evidence/` не входят
в публичный репозиторий; публикуется [резюме проверок](docs/reviews/prototype-readiness.md).

Репозиторий опубликован для оценки статического интерфейса. Настоящий финансовый
учёт и шифрование не начинаются без одобрения макета пользователем.
О взаимодействии — [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
