# MultiTracker: карта полного статического интерфейса

Дата: 2026-09-30. Карта описывает сценарии текущих исходников; наличие кода
не означает подтверждённую приёмку. Требования — в
[брифе](docs/design/brief.md) и [R01–R21](openspec/changes/complete-prototype/specs/readiness/spec.md),
наблюдения и ограничения — в [аудите](docs/reviews/prototype-readiness.md).
Исторический первый этап сохранён в [OpenSpec](openspec/changes/clickable-prototype/design.md).

## Карта разделов

| Раздел        | Сценарии макета                                                                                                                                                                                      |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Обзор         | Выбор одного, всех или нескольких портфелей; стоимость, себестоимость, результат и причины; вымышленная динамика с периодами/таблицей; состав, отчёт, активы и последние покупки.                    |
| Портфели      | Фиксированные Tradernet, Binance, Bybit; выбор группы/нескольких портфелей; формы создания, изменения, архива и удаления портфеля, счёта и группы. Счета показываются внутри портфеля.               |
| Операции      | Покупка, продажа, ввод, вывод, перевод, обмен, доход, комиссия, начальный остаток, корпоративное действие. Поиск, фильтры счёта/типа/актива/дат, порядок; подробности, правка и удаление примера.    |
| Импорт        | Источник и назначение, встроенный файл, сопоставление, ошибки/повторы и результат; история, подробности, отмена и сверка примера.                                                                    |
| Подключения   | Tradernet/Binance/Bybit, кошелёк и банковский счёт; портфель/счёт, начало истории, права чтения и фиксированный токен; проверка, ошибка и отключение примера.                                        |
| Синхронизация | Автоматический/ручной режим, время и статус, ошибка сети/повтор; устройства/отзыв; сравнение и выбор версии конфликта.                                                                               |
| Настройки     | RU/EN, RUB/USD, скрытие сумм, плотность, уведомления и статические состояния; блокировка/разблокировка, восстановление/утрата ключа, резервная копия/восстановление, экспорт и удаление как примеры. |

Общие элементы: пометка демонстрации, помощь с тремя шагами и словарём,
ссылка к основному содержимому, сведения о приватности. На широком экране —
боковая навигация; на телефоне — «Обзор», «Портфели», «Операции», «Ещё».
Адресный фрагмент обозначает раздел; неизвестный адрес открывает обзор.

## Потоки и состояние

```text
портфели / группа / выборка → обзор → актив → ручная оценка-пример
                                  → отчёт → форма экспорта-примера
каталог / денежный остаток  → форма операции
источник и счёт → файл-пример → сопоставление → ошибки/повторы → результат
раздел / язык / валюта / вид → представление фиксированных данных
```

Финансовые примеры не меняются при сохранении. Дополнительные строки журнала
показывают типы операций, не добавляются в расчёт трёх покупок. Создание,
архивирование и удаление сущностей — формы и подтверждения демонстрации,
а не изменение постоянного набора портфелей. Черновик проверяется, отменяется
или закрывается с сообщением; повторное сохранение имеет новое объявление.

Настройки и состояния вспомогательных страниц живут в памяти вкладки;
эти страницы сохраняются смонтированными за `hidden`. Перезагрузка возвращает
исходные значения. Диалог закрывается при уходе с раздела. Переходы между
разделами поддерживают «Назад/Вперёд» и перевод фокуса в основной контент.
Сохранение фильтров отдельных вложенных сценариев проверяется по R01/R17,
не предполагается автоматически из сохранения общих настроек.

Импорт использует встроенные строки и ключи сопоставления; настройки источника
редактируемы, имя файла и токен подключения — только для чтения. Подключение,
отзыв устройства, конфликт и блокировка меняют учебное состояние; настоящих
служб или проверки личности нет. Заблокированный пример в настройках
не ограничивает доступ ко всему макету.

## Результат, активы и отчёт

Цена + курс + совместный эффект − комиссии объясняют выбранные учебные покупки.
Для всей выборки: 6 900 + 77 400 + 2 700 − 580 = 86 420 RUB;
80 − 6 = 74 USD. Это проверяемая сцена, не универсальная модель доходности.
Доходы и закрытый результат для неё нулевые; IRR и TWR отсутствуют.

У актива есть позиция, себестоимость, результат, цена/источник/дата, история
покупок, вымышленный график и форма ручной оценки. Оценка не меняет котировку.
Каталог охватывает акции, фонды, облигации, криптоактивы и деньги; денежный
остаток равен 0 RUB/0 USD и ведёт в форму начального остатка.

В отчёте период меняет строки и их количество, а не текущую оценку позиции
или себестоимость всей выборки. Валюта отчёта выбирается отдельно. CSV/PDF —
выбор в форме демонстрации, файл не создаётся. Скрытие сумм распространяется
на детали, графики, состав и отчёт; это сценарий показа, не защита данных.

## Общий визуальный язык

Токены заданы в [src/base.css](src/base.css), композиция — в остальных CSS-модулях.

| Токен                           | Значение                                                                   |
| ------------------------------- | -------------------------------------------------------------------------- |
| Фон / бумага                    | `#f6f5ef` / `#fffdf8`                                                      |
| Текст / второстепенный текст    | `#293432` / `#616965`                                                      |
| Акцент / отрицательное значение | `#245c4a` / `#a8473f`                                                      |
| Разделитель / граница поля      | `#d5d8cf` / `#7e8982`                                                      |
| Фокус                           | `#365ccb`, обводка 3 px, отступ 3 px                                       |
| Шрифт                           | Inter, Segoe UI, Arial, sans-serif; используются доступные локально шрифты |
| Размер                          | Основа 16 px / 1.5; подписи и контекст от 14 px; табличные цифры           |
| Скругление                      | Поля/кнопки 6 px, диалог 10 px                                             |
| Отступы / управление            | 8/12/16/20/24/28/32 px; обычное управление от 44 px                        |

Открытая последовательная композиция с разделителями; вспомогательные страницы
используют ту же типографику и поля. Нет загрузки внешнего шрифта, аналитики
или набора одинаковых крупных карточек. Действия длинных форм закреплены внутри
диалога; сообщение результата остаётся в обычном потоке страницы и имеет кнопку
закрытия. На телефоне оставлен запас прокрутки перед нижней навигацией. Фактические размеры,
контраст и отсутствие перекрытия требуют браузерного наблюдения.

## Границы проверки

[План доступности](docs/design/accessibility-plan.md) требует RU/EN,
375/1440 px, клавиатуру, фокус, ошибки, отмену и повторные действия; дополнительно
320 CSS px, 375×500 и настоящее увеличение браузера 200%.
Прежние наблюдения фазы 1 не подтверждают новые сценарии.

Нет настоящих данных, файлов, ключей, API, сервера, базы, шифрования,
котировок и синхронизации. Экранный диктор, аппаратная экранная клавиатура,
испытания новичков/возрастных групп, удалённый GitHub run и исполнение навыка
в Claude Code не считаются проверенными без соответствующих доказательств.
Незапущенное и неизвестное не получают PASS.

[Дорожная карта](docs/plans/2026-09-30-roadmap.md) описывает будущую реализацию.
Её начало требует пользовательского одобрения полного макета; успешная сборка
или старый отчёт этого одобрения не заменяют.
