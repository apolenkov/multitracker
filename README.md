# MultiTracker

Статический кликабельный макет приложения для учёта портфелей на React,
TypeScript и Vite. Одиннадцать разделов: **Обзор, Портфели, Операции, Рынки,
Избранное, Аналитика, События, Импорт, Подключения, Синхронизация, Настройки**.
Tradernet, Binance и Bybit представлены
вымышленными примерами. Язык — русский/английский; валюты расчёта и показа
выбираются отдельно из RUB/USD. Тёмная, светлая и системная темы используют
синий акцент действий и выбора, отдельные цвета финансового результата.
На телефоне четыре пункта: Обзор, Рынки, Избранное, Ещё; все 11 разделов доступны.
[Новый план дизайна](docs/plans/2026-09-30-design-arena.md) основан на четырёх
разборах [135 экранов, форм и состояний](docs/design/form-inventory.md).
[Текущая приёмка](docs/design/arena/acceptance.md) фиксирует пройденные проверки
и оставшиеся результаты; пользовательское одобрение ещё не получено.
[Прежняя проверка дизайна](docs/reviews/design-revision.md) сохранена как история.

Текущая задача — показать полный интерфейс до начала настоящей реализации.
Область и приёмка: [план полного макета](docs/plans/2026-09-30-complete-prototype.md)
с [R01–R21](openspec/changes/complete-prototype/specs/readiness/spec.md) и
[план расширения Delta](docs/plans/2026-09-30-delta-capabilities.md) с
[D01–D07](openspec/changes/delta-capabilities/specs/exploration/spec.md).
[Карта каталога Delta](docs/design/delta-capabilities.md) связывает возможности
с конкретными сценариями. Новая приёмка ещё не завершена.
Карта интерфейса — в [DESIGN.md](DESIGN.md). Первый, более узкий этап сохранён
отдельно в [OpenSpec](openspec/changes/clickable-prototype/design.md).

Рынки, наблюдение и оповещения, аналитика, календарь и лента показывают
вымышленные примеры; настройки добавляют монохром и предпросмотр виджетов.
Услуги eToro исключены. Виджеты ОС, аудио, настоящие уведомления, новости
и внешние службы не подключаются.

Формы позволяют временный ввод и показывают демонстрационный результат.
Сохранение не создаёт операции и не меняет фиксированные финансовые примеры.
Наблюдение и правила оповещений меняют только локальные списки, а аналитика
использует самостоятельные учебные наборы, не расчёт текущих трёх покупок.
Черновики и настройки существуют в памяти вкладки; перезагрузка возвращает
исходное состояние. Файл для импорта и ключ подключения — встроенные примеры.
Экспорт не создаёт файл, подключение и синхронизация не отправляют запросы.

**Не вводите реальные финансовые данные, пароли и ключи.** В макете нет сервера,
базы, настоящих котировок, API, загрузки файлов, хранения и шифрования.
Учебные расчёты не заменяют финансовый движок. Будущая реализация описана в
[дорожной карте](docs/plans/2026-09-30-roadmap.md); переход к ней требует одобрения
полного макета пользователем.

## Запуск

Закреплён Node.js **24.21.0** в [.nvmrc](.nvmrc); используйте эту версию для
воспроизводимых проверок. Зависимости закреплены в `package-lock.json`.
Полная проверка также требует **Gitleaks 8.30.1** из
[официального выпуска](https://github.com/gitleaks/gitleaks/releases/tag/v8.30.1).

```sh
nvm install
nvm use
npm ci
npm run dev
```

Откройте адрес Vite, обычно `http://127.0.0.1:5173`. Сервер слушает локальный
интерфейс. `npm run build` создаёт `dist/`, `npm run preview` показывает сборку.

## Проверки

```sh
npm run check
```

| Команда                | Назначение                                                                             |
| ---------------------- | -------------------------------------------------------------------------------------- |
| `npm run format:check` | Prettier для авторских TypeScript/CSS, ширина 100                                      |
| `npm run typecheck`    | Строгие типы приложения, тестов и конфигурации                                         |
| `npm run lint`         | ESLint и Oxlint, включая доступность JSX                                               |
| `npm run complexity`   | ESLint и предел длины CSS-файлов                                                       |
| `npm run test:gates`   | Отрицательные и безопасные примеры проверяют реальные запреты                          |
| `npm test`             | Проверки поведения и учебной модели через `node:test`                                  |
| `npm run build`        | Проверка типов и сборка Vite                                                           |
| `npm run security`     | Линтеры и аудит всех зависимостей с порогом `high`                                     |
| `npm run secrets`      | Gitleaks в текущих файлах                                                              |
| `npm run check`        | Вся обязательная цепочка; первая ошибка прекращает запуск                              |
| `npm run test:ui`      | Наблюдения навигации и отдельных действий через agent-browser; нужен запущенный сервер |

TypeScript: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`.
Для авторского кода: файл ≤300 строк, функция ≤50, обычная и когнитивная
сложность ≤10. JSX, комментарии и пустые строки считаются. Запрещены `let`,
мутации объектов/массивов, отключения правил и небезопасные утверждения типов.
`npm run format` меняет исходники, тесты и конфигурацию, а не документы.

Успешная цепочка не доказывает полноту интерфейса. Для каждого сценария нужны
наблюдения через agent-browser на 375/1440 px и в RU/EN: действия, ошибки,
отмена, клавиатура, фокус и контраст. Неизвестный результат остаётся непроверенным.
Датированные результаты и ограничения — в
[публичном отчёте](docs/reviews/prototype-readiness.md). Сырые журналы и снимки
сохранены локально в `docs/audits/` и `docs/evidence/`, исключённых из Git.
Прежние проверки не заверяют расширение D01–D07 и каталог Delta.
Для текущей редакции `npm run check` прошёл: 32 теста и 39 проверок ограничений;
Linux `test:ui` — 63/63 PASS, строгая проверка OpenSpec — PASS.
[Приёмка арены](docs/design/arena/acceptance.md) отделяет эти результаты от
основного пакета из 162 кадров и восьми итоговых кадров обзора/покупки на 320 px.
Единственное независимое ревью подтвердило F1–F3 и приняло решение **ship**
в пределах проверенного статического макета; открытых существенных замечаний нет. Полная матрица всех форм и адаптивности
не объявлена пройденной.
Удобство для разных возрастов требует отдельных испытаний
с представителями аудитории.

`test:ui` использует agent-browser **0.38.1**, создаёт собственную сессию и
читает `MULTITRACKER_UI_URL` (по умолчанию `http://127.0.0.1:5173`). Эта отдельная
команда не входит в `check` и не заменяет матрицы R01–R21, D01–D07 и каталога.

Для macOS проверенный запуск с видимым окном:

```sh
AGENT_BROWSER_HEADED=true npm run test:ui
```

На историческом кандидате семи разделов 2026-09-30 он и отдельный Linux-запуск
без окна дали по 34/34 PASS. Это результат до расширения Delta.
Прежний сбой macOS без окна сохранён как непроверенный результат; подробности,
полная матрица форм и ограничения — в [итоговом отчёте](docs/reviews/prototype-readiness.md).

## Организация проекта

```text
src/                 интерфейс и стили
  model/             чистая учебная арифметика
  forms/             формы вымышленных записей
  records/           портфели и журнал
  insights/          представления результата и активов
  market/            рынки, наблюдение и правила оповещений
  analytics/         самостоятельные учебные аналитические сцены
  events/            календарь, лента, сводки и предпросмотр виджета
  demo/              вспомогательные сценарии
tests/               проверки поведения
scripts/             проверки инструментов и правил
docs/                требования, планы, решения, исследования и доказательства
openspec/            спецификации первого, полного и расширенного макетов
skills/              переносимый product-readiness
.github/             подготовленные проверки и публикация
public/              статические материалы и лицензии зависимостей сборки
```

Комплексный аудит запускается по явному запросу с навыком `product-readiness`:
прочитайте [его SKILL.md](skills/product-readiness/SKILL.md) в Claude Code или Codex.
Нужные сторонние навыки выбираются по области и доступности; весь набор не
загружается автоматически. [Оценка поведения и один запуск Claude Code](docs/reviews/prototype-readiness.md#навык-product-readiness)
имеют отдельные границы; это не полный аудит приложения в Claude Code.

Публичный репозиторий — [apolenkov/multitracker](https://github.com/apolenkov/multitracker).
Задачи обсуждаются в [GitHub Issues](https://github.com/apolenkov/multitracker/issues);
личный бэклог владельца не требуется участникам. Конфигурация GitHub Actions предназначена для
проверок ([check.yml](.github/workflows/check.yml)) и ручной публикации статической
сборки ([pages.yml](.github/workflows/pages.yml)); локальные проверки не являются
запуском GitHub. [Фактический запуск №36713961789](https://github.com/apolenkov/multitracker/actions/runs/36713961789)
завершился SUCCESS на прежнем кандидате: 27 тестов, 39 примеров правил, UI 34/34.
Это историческая проверка семи разделов, а не текущего расширения Delta.
