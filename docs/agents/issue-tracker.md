# Задачи и источник требований

Проектный трекер — [GitHub Issues](https://github.com/apolenkov/multitracker/issues).
Перед новой задачей поищите дубликаты. В обсуждении зафиксируйте цель,
принятые решения, выполненное, проверки и следующие шаги. Чувствительные
сведения передаются по [правилам безопасности](../../SECURITY.md).

Переносимые требования находятся в
[OpenSpec](../../openspec/changes/complete-prototype/specs/readiness/spec.md),
[плане](../plans/2026-09-30-complete-prototype.md) и [DESIGN](../../DESIGN.md).
Исходный запрос пользователя имеет приоритет над суженным локальным планом.
Публикация репозитория не является одобрением макета для настоящей реализации.

Карточки `TASK-060.*` в исторической дорожной карте относятся к личному
Backlog CLI владельца. Это необязательный частный инструмент сопровождения,
а не публичные номера Issues. Участникам не нужен доступ к личному бэклогу,
его локальному каталогу или инструкции для работы с ним. Существенные
проектные решения сохраняются в `docs/decisions/` и обсуждаются публично.
