# decision-084 — Полный инвентарь форм и единая сборка дизайна

Статус: accepted. Дата: 2026-09-30. Backlog Decision: decision-084.
Уточняет процесс UI из [decision-083](decision-083-complete-prototype-and-scenario-modules.md).

## Контекст

Пользователь отклонил последовательные косметические правки: монохромность,
слишком тёмные поверхности, полотно текста, неустойчивые значки и перегруженные
формы. Он поручил применить четыре навыка ко всем формам, свести рекомендации
и сделать цельную редакцию. Технические проверки не заменяют оценку внешнего вида.

## Решение

1. Использовать единый [инвентарь](../design/form-inventory.md) из 135 устойчивых
   ID для экранов, форм и важных состояний. Каждая линза оценивает каждый ID,
   отдельно отмечая отсутствие наблюдения. Рекомендация не равна проверке действия.
2. Применить `frontend-design`, `ui-ux-pro-max`, `web-design-guidelines` и
   `impeccable` независимо; консолидировать противоречия до реализации.
   [План](../plans/2026-09-30-design-arena.md) содержит принятые решения и критерии.
3. Выполнить одну согласованную сборку существующими React/CSS средствами:
   функциональный цвет, компактная оболочка, предметные группы полей,
   последовательные значки, короткие объяснения рядом с действием.
   Новые зависимости и пустые архитектурные слои не нужны.
4. Проверить результат пакетно на узком и широком экране, исправить найденные
   проблемы вместе и подтвердить изменения. Один независимый итоговый обзор
   проверяет требования, код, организацию репозитория и доказательства.
5. Не объявлять неизвестные результаты пройденными. Изолированный Linux допустим
   для воспроизводимого запуска `agent-browser`, если локальный инструмент
   зависает; исходный неуспешный журнал сохраняется.

## Последствия

Результат остаётся статическим макетом на вымышленных данных. Список возможностей
Delta и границы eToro не меняются. Дополнительные языки требуют списка владельца;
принятие внешнего вида остаётся за владельцем. Публичные документы содержат
выводы, а сырые снимки и журналы сохраняются локально вне Git.
