# decision-090 — Быстрая проверка DOM перед строгими 135 сценариями

Статус: accepted. Дата: 2026-09-30. Backlog Decision: decision-090.
Уточняет [decision-084](decision-084-form-arena.md) и исполнение
[плана layout-review](../plans/2026-09-30-layout-review.md).

## Контекст

Проверки пропускали нативные summary и путали достижимость после прокрутки
с исходной видимостью кнопки. Исторические F1–F9 относятся к разбору 22:25;
в снимке 1e64f81 F1/F2 уже исправлены. Пользователь отдельно потребовал,
чтобы основное действие сразу было видно во всех десяти типах операций.
Прежнее доказательство достижимости прокруткой не доказывает это требование.

## Решение

1. До правок сохранить неизменяемые исходники, сборку и SHA-256. Первый
   baseline 1e64f81 сохранён локально: manifest 131 файла и baseline-dist.
   После первых измерений root разрешает непересекающиеся области; полный
   обход исходного состояния продолжает работать по запечатанной копии.
2. Быстрая проверка перечисляет DOM-управление, включая details > summary,
   делает настоящий click/Enter и фиксирует наблюдаемое действие. Защищённые
   сдвиги ограничены 2 CSS px; centerYDelta — сигнал разбора, а не общий запрет.
   Исходную видимость измеряют до hit-test, который может прокрутить страницу.
3. Чувствительность F1/F2 доказывают отдельными контролируемыми историческими
   CSS-пробами RED при текущем GREEN; пробный CSS гарантированно удаляют.
   Исходный RED нового F4 сохраняют отдельно от исправленного результата.
4. Smoke нужен для быстрой обратной связи и не заменяет инвентарь. После
   последней правки заново проходят все 135 ID в обязательных контекстах,
   npm check, UI и проверки документа дизайна. Старые PASS не переносят,
   неизвестное следствие не получает PASS, правила качества не ослабляют.
5. Один независимый итоговый обзор получает полный пакет и проверяет
   исправления находок в том же обзоре. Визуальное одобрение владельца
   остаётся отдельным шагом; инженерные проверки не заменяют его.

## Последствия

Мелкие дефекты раскладки выявляются раньше дорогого полного обхода. Исходные
неудачи и исправления можно сопоставить без подмены сборки. Smoke может
проходить, пока строгий набор или визуальная приёмка ещё ожидаются.
Сырые снимки, журналы и baseline находятся в ignored docs/audits; публичный
план содержит статусы и границы подтверждённого. Настоящие данные, внешние
службы, слияние и реализация продукта не входят в это решение.

Локальное исходное доказательство:
`docs/audits/2026-09-30-layout-smoke/baseline-1e64f81/manifest.json`.
