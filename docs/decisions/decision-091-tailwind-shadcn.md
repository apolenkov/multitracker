# decision-091 — Tailwind и shadcn как основа готовых примитивов

Статус: accepted. Дата: 2026-10-01. Backlog Decision: decision-091.
Продолжает [decision-085](decision-085-mintlify.md): оформление и палитра не меняются.

## Контекст

До сих пор единственными зависимостями времени выполнения были React и React DOM.
Меню действий и переключатели на телефоне и десктопе написаны вручную поверх
нативных details и select; доступность, клавиатура и позиционирование у каждого
своя. Нужны готовые, проверенные сообществом доступные примитивы.

## Решение

1. Подключить Tailwind v4 (`tailwindcss`, плагин `@tailwindcss/vite`), примитивы
   Radix (`radix-ui`) и вспомогательные `clsx`, `tailwind-merge`
   (`class-variance-authority` не понадобился и удалён). Это первая зависимость сверх React; плагин Vite — только
   для сборки (devDependencies), остальное — среда выполнения.
2. Preflight (сброс стилей Tailwind) не подключается: `src/tailwind.css` импортирует
   только `theme.css` и `utilities.css`. Иначе сброс перекрыл бы `base.css` и
   изменил бы внешний вид всего макета.
3. Токены Tailwind в `@theme` ссылаются на существующие переменные
   `src/appearance.css` (`--color-ink: var(--ink)` и т. д.; рост и падение —
   `--green` и `--red`), поэтому темы, монохром и контраст остаются в одном месте.
   Радиусы: `--radius-control` 8 px, `--radius-panel` 12 px.
4. Конфигурация shadcn (`components.json`, стиль new-york, `iconLibrary: none`):
   значки берутся из `src/Icon.tsx`, Lucide не добавляется. Алиас `@/` указывает
   на `src/`, вспомогательная функция `cn` находится в `src/lib/utils.ts`.
5. Нативные `dialog`, `details` и `select` сохраняются: они уже покрывают нужную
   семантику, а замена изменила бы проверенное поведение. Shadcn применяется
   только там, где нативного эквивалента нет или он хуже (меню действий, вкладки).

## Последствия

Появляются новые зависимости и требование проверять `npm audit`. Внешний вид
не меняется: утилиты Tailwind действуют только на элементах, где их класс указан.
Правила качества (300 строк CSS, сложность, форматирование) действуют и для нового кода.
Утилиты Tailwind подключены без слоя и соревнуются с ручными стилями по
специфичности: утилита-класс побеждает правила по элементам из `base.css`
(например `button { … }`), но не правила классов равной или большей специфичности.
Токены объявлены через `@theme inline`, поэтому локальные переопределения
(например `--primary` в `.balance-panel`) доходят до утилит.
