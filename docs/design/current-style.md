# MultiTracker: текущее оформление

Дата: 2026-09-30. Статус: CSS и приложение заморожены для адаптации палитры
Bentley. Финальные локальные инженерные проверки и проход 135/135 ID выполнены;
GitHub CI успешны, единственное независимое ревью — SHIP.
Ожидается визуальная приёмка владельцем.
Сохраняется единый продуктовый бриф после обратной связи владельца,
сведённый из frontend-design, ui-ux-pro-max и web-design-guidelines.
Монохром и квадратные углы не задают оформление по умолчанию.

## Договор

Светлый moss-холст `#f3f1e8` включён по умолчанию: панели `#fffdf8`,
текст `#23342d`. Общая Race Green-панель стоимости и истории `#394d45`
занимает полную ширину; внутри светлая teal-линия `#b9e9d9` и blush-кнопка
`#e7cfb9` с тёмной подписью. Вне панели основное действие — `#394d45`
с белой подписью. Состав и отчёт получают teal-зону `#d6e2da`,
выбранный маршрут/период — blush `#e7cfb9`.

Тёмная тема самостоятельна: холст `#14241e`, панели `#20362e`,
история `#315047`, действие `#a8d5bf`, линия `#a9e5d0`,
состав/отчёт `#29473f`, выбранное состояние `#b99b85`.
Системная тема следует устройству; монохром включается только по выбору.

| Проблема из обратной связи        | Изменение кандидата                                                                                                                                                                                          |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Монохром и слабая выразительность | Race Green-панель, teal-зоны состава и отчёта, blush-выбор; BTC оранжевый, MSFT синий, TWT бирюзовый. Рост и падение используют отдельные зелёный и красный оттенки.                                         |
| Вложенные коробки и сдвиг обзора  | Общая заливка истории без отдельной рамки/фона/внутренних отступов; 38:62 стоимость/график при ширине больше 1100 px, вертикально ниже. «Деньги и классы активов» открывает диалог, сохраняя размеры обзора. |
| Неаккуратные элементы выбора      | Нативный select 44 px с общим SVG-шевроном 16 px. Видимые подписи «Язык / Тема / Показ в» и «Language / Theme / Display in». Управление 8 px, панели/диалоги 12 px.                                          |
| Разные значки и начальная рамка   | Общие SVG 22 px; шеврон кнопки каталога 18 px. Фокус основного содержимого вокруг заголовка страницы.                                                                                                        |

Последние подтверждённые исправления: строки главной панели `min-content 1fr`
(до 1100 px — `auto`) удерживают результат при раскрытии графика; аналитические
панели используют `minmax(0, 1fr)`, таблицы прокручиваются внутри своего блока.
Строки последних операций выровнены сверху. Переходы 200 ms ограничены цветом
текста, фона и границы; уменьшение движения отключает их.
Состояние «Пусто» в настройках показывает нулевой обзор и пустые позиции/состав,
без вымышленного графика, отчёта и последних покупок. Каталог остаётся отдельным диалогом.

Это описание реализации, а не утверждение пройденной визуальной проверки.
Сохраняются все одиннадцать разделов, RU/EN, скрытие сумм и отдельные валюты
стоимости и результата. Все данные вымышлены; сохранение показывает пример.
Новые формы и рекламная страница не добавляются. Локальный Inter Variable 4.1
под SIL Open Font License 1.1 сохранён: читаемые размеры и насыщенность,
без переноса тонкого текста из образца. Основной текст 16 px, подписи от 14 px,
управление от 44 px. Сторонние логотипы, рекламное содержание и внешние шрифты отсутствуют.

Предоставленная владельцем палитра Bentley адаптирована к финансовому макету;
это не копия автомобильного сайта и не утверждение о его свойствах.
Второе мнение Claude в локальном `docs/audits/2026-09-30-product-ui/claude-review.json`
основано на трёх снимках прежнего кандидата и чтении CSS. Оно помогло различить
роли поверхностей, но не проверяло взаимодействия, RU/EN и все разделы.
Прежний текст Alfa остаётся историческим материалом.

## Будущий мобильный продукт

Выбран мобильный веб с будущей установкой на главный экран как прогрессивное
веб-приложение (PWA). Сейчас пакет использует React + Vite + CSS.
Tailwind и shadcn/ui предложены для будущего интерфейса; они и установка PWA
пока не подключены. Не выдавать предложение за реализованную возможность.
