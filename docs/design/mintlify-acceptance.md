# Приёмка Mintlify

Статус: исторический документ Mintlify, заменён новым направлением владельца.
Текущее основание — [Текущее оформление](current-style.md). Результаты ниже
относятся к кандидату `f6549db` и исправлению запуска браузера `2ddca9d`;
они не подтверждают новую редакцию.

Дата: 2026-09-30. Основание: [план](../plans/2026-09-30-mintlify.md),
[решение 085](../decisions/decision-085-mintlify.md),
[M01–M03](../../openspec/changes/archive/2026-10-02-mintlify-redesign/specs/presentation/spec.md).
Базовый коммит до переделки — `c296541`; работа ведётся в `fix/prototype-design`,
[черновик PR3](https://github.com/apolenkov/multitracker/pull/3).

## Результат и границы

Выбранное владельцем оформление Mintlify заменяет прежнюю синюю палитру:
светлая тема по умолчанию, отдельная графитовая тёмная тема, локальный Inter 4.1,
мятный акцент и контрастное чёрное/белое главное действие. Обзор соединяет
сумму, динамику и активы; состав занимает вспомогательную колонку.
На телефоне поля операции идут в одну колонку. Все одиннадцать разделов,
RU/EN, независимые валюты расчёта и отображения сохраняются.

Это статический кликабельный макет. Сохранение операции показывает пример,
настоящих данных, файлов, ключей, подключения к брокерам и шифрования нет.
Одобрение внешнего вида владельцем ещё не получено. Старое решение `ship`
в [приёмке арены](arena/acceptance.md) относится к другому оформлению.

## Визуальные доказательства

Локальный каталог: `docs/audits/2026-09-30-mintlify/` (исключён из Git).
Пакет `capture-evidence-2026-09-30T15-34-10.464Z/` содержит исходный `index.json`,
исправленный сбор `correction.json`, PNG и наблюдения DOM.
Сырые неуспешные попытки сохранены. Переход на тот же URL без перезагрузки
оставлял открытый диалог в сборщике; повторы с перезагрузкой отделены от
дефектов приложения, прежние попытки задним числом не объявлены успешными.

Пакет охватывает 44 сочетания раздела/ширины/темы, 16 пилотов обзора/покупки
на RU/EN, восемь контрольных случаев 320/768 и 17 выборок форм (десять типов
операции и семь диалогов настроек). В трёх первоначальных кадрах узкого обзора
ошибочно оставался открытый диалог; они не доказывают чистый обзор.
Их заменяет отдельный `final-spot-confirmation.json`: отсутствие диалога
проверено до и после каждого снимка. Подробности — `capture-report.md`.
Снимки не доказывают прохождение всех 135 сценариев инвентаря.

Обрезка RU исправлена ширинами мобильных переключателей 56/104/70 px;
пять подтверждающих кадров — в `shell-confirmation/`. Контраст светлой границы
с серой поверхностью повышен с 2,98 до 3,18:1. Вычисленные цвета из браузера
сохранены в `contrast-light.json` и `contrast-dark.json`: основной и финансовый
текст на холсте/панели/поверхности ≥4,97:1 в светлой и ≥4,62:1 в тёмной теме.

Итоговое ревью выявило переносы внутри сумм в узкой настольной таблице.
До 1279 px таблица теперь занимает обе колонки. Подтверждены 768, 901, 1101,
1200/1201, 1279/1280 и 1440 px, RU/light и EN/dark; отдельные случаи используют
USD для стоимости и RUB для результата. Доказательства —
`after-table-boundary-dom.json` и `after-table-*.png`. В проверенных случаях
нет горизонтального переполнения и разрывов внутри чисел.
Проверка системной темы также ожидает наблюдаемое обновление `theme-color`
перед сравнением; это устраняет гонку теста без изменения поведения приложения.

## Внешние материалы и дальнейшая приёмка

Mobbin подключён к официальному серверу, авторизация завершена. В текущей
среде и отдельном ограниченном запуске CLI инструменты поиска не появились;
поиск банковских экранов не выполнен. Повторный вход не требуется.

Единственное независимое итоговое ревью дало **ship для передачи владельцу**:
158/158 хешей сверены независимо, открытых существенных замечаний нет.
Закрыты переносы в таблице, три неверных обзорных кадра, гонка теста темы
и устаревшие утверждения основной документации. Отчёт сохранён в
`docs/audits/2026-09-30-mintlify/final-review.md`.
Далее — визуальная приёмка владельцем; слияние и настоящая реализация
до неё не начинаются. Дополнительные языки
пока не перечислены. Экранный диктор, физическая мобильная клавиатура и
испытания с людьми разных возрастов в этом проходе не проверялись.

GitHub Actions для `f6549db` прошли `npm run check`, но остановились по лимиту
10 минут при скачивании системных пакетов установщиком браузера; действия
интерфейса в этих двух запусках не выполнялись. Журналы — `ci-push-full.log`
и `ci-pr-full.log` в каталоге доказательств. В workflow устранена лишняя установка:
используется Chrome из [образа GitHub](https://github.com/actions/runner-images/blob/main/images/ubuntu/Ubuntu2404-Readme.md)
через [поддерживаемый путь исполняемого файла](https://github.com/vercel-labs/agent-browser#custom-browser-executable).
Отсутствие Chrome останавливает шаг; версия CLI, проверки и лимит времени сохранены.

Удалённый запуск относится к конкретному коммиту; его текущий статус —
[Checks PR3](https://github.com/apolenkov/multitracker/pull/3/checks).
Старые успешные GitHub Actions не считаются проверкой переделки Mintlify.
