# Отчёт о сокращении объёма: семь разделов

Дата: 2026-10-01. Ветка `devin/scope-cut`, worktree `.claude/worktrees/devin-scope`.
Решение владельца: в макете остаются Обзор, Портфели, Операции, Импорт,
Подключения, Синхронизация, Настройки. «Рынки», «Избранное», «Аналитика» и
«События» убраны; полная версия одиннадцати разделов сохранена тегом
`prototype-full-11-sections`. Архитектурное решение — `docs/decisions/decision-093-seven-section-scope.md`.

## Что изменено

- Навигация и маршруты: семь маршрутов (`#overview`, `#portfolios`, `#history`,
  `#import`, `#connections`, `#sync`, `#settings`); неизвестный хэш открывает
  Обзор. Группа «Исследование» удалена из сайдбара: «Мой портфель» —
  Обзор/Портфели/Операции, «Данные и настройки» —
  Импорт/Подключения/Синхронизация/Настройки. Нижняя панель телефона:
  Обзор / Портфели / Операции / Ещё («Ещё» ведёт на остальные четыре раздела).
- Убраны ссылки на удалённые разделы, их словари, стили и сценарии из
  активного кода; `ui-exploration.ts` переименован в `ui-helpers.ts`.
- Денежные строки обзора: вместо «Задать остаток» — видимая кнопка-карандаш
  44×44 px с доступным именем «Изменить остаток: RUB/USD», открывающая форму
  начального остатка с валютой строки.
- Предпросмотр виджета оставлен только в Настройках и только для портфеля.
- Подключения: проверка «Настроить → проверить/сохранить → отключить →
  отменить» покрыта новым сценарием.
- Удалена недокументированная кнопка «Купить» в диалоге актива: она заменяла
  asset-dialog диалогом операции, и элемент, открывший диалог, пропадал вместе
  с ним — Escape не мог вернуть фокус. DESIGN.md задаёт путь покупки через
  «Добавить операцию».
- Проверки ui-smoke исправлены: геометрия действий строк признаёт
  `tr.holding-row` (денежные строки обзора); якоря внутри sticky/fixed-
  контейнеров исключены из замера сдвига — их box уже содержит stick-офсет,
  двойной учёт scrollTop давал ложные `disclosure-shift`.
- Документация: DESIGN.md, README, AGENTS.md, PRODUCT.md, agent-handoff,
  current-style, delta-capabilities, form-inventory (53 записи помечены «вне
  текущего объёма», FORM-028/092/093 переписаны), openspec delta-capabilities
  и план Delta помечены историческими.

## Промежуточные находки, закрытые до итогового прогона

- Первый прогон ui-smoke после вычитки упал с exit 1: все 6 состояний Обзора
  получили `state-not-verified` — проверка действий строк падала на
  `tr.holding-row` (исправлено, коммит 2d19fd9).
- После исправления ui-smoke показал реальные находки на Обзоре:
  ложные `disclosure-shift` на sticky-заголовке диалога (исправлено там же) и
  связанные с подменой диалога `escape-return-focus`/`dialog-not-reopened`
  (устранены удалением кнопки «Купить», коммит 2e921ad).

  показанная на них раскладка совпадает с проверенной сборкой.
