## Отклонения от плана

- Задача 1: помимо двух `save(...)` из плана (History, Portfolios) убраны три `notify(...)` при удалении в демо-разделах (`connection-sync`, `sync-panel`, `import-history`): эти вызовы теперь ведут в ту же глобальную плашку и давали бы дубль поверх `RowNotice` — критерий «ровно один role=status» из плана выполняется только без них.
- Задача 1: плашка оставлена в DOM на прежнем месте (`<StatusMessage>` между `PageHeading` и `PageContent`), как в плане; `position: fixed` вынес её из потока — DOM-позиция на раскладку не влияет.
- Задача 2: источник оказался третьим, не из плана: скрытый график рендерится `<p class="history-plot-hidden">` вне обёртки `.history-chart`, у которой `margin-top: 12px` — терялись ровно 12 px. Ни «маска-круги», ни `▲`, ни строки grid не участвовали: замеры детей показали 309→297 только у `.value-history`. Правка — один `margin-top: 12px` на `.history-plot-hidden`.
