# Редакция дизайна по образцу Delta

30 сентября 2026 года владелец отклонил первое оформление и попросил копию
Delta. Макет переработан по её официальным изображениям: тёмные поверхности,
крупная стоимость, результат перед графиком, компактные активы и цветной состав.
Настольная раскладка — адаптация мобильного образца, не подтверждённая копия
закрытого кабинета Delta. [Источники](../design/references.md).

Добавлены светлая и системная темы, заметный выбор языка, отдельные валюты
расчёта и отображения. Смена отображения не изменяет результат в базовой валюте.
Пример: стоимость 3 440 USD, результат +86 420 RUB. Итог обозначен как результат
за всё время, независимо от периода учебного графика. Нового движка нет.

Проверено в текущей редакции:

- `npm run check`: код 0, 27 тестов, 39 проверок запретов, строгие типы,
  форматирование, линтеры, сборка, аудит зависимостей и поиск секретов.
- `AGENT_BROWSER_HEADED=true npm run test:ui`: код 0, 36 PASS,
  включая независимость валют и все три темы с обоими системными предпочтениями.
- Наблюдение снимков 320/375/768/1440 px, светлого и тёмного оформления,
  русских/английских подписей и формы операции; горизонтального переполнения нет.
- Автоматический анализ доступности выбранных экранов: 0 нарушений.
  Неопределённый контраст декоративного символа BTC сохранён в протоколе.
  Сообщение после сохранения в светлой теме исправлено до контраста 5,00:1;
  повторная проверка этого состояния: 0 нарушений, 0 неопределённых результатов.
- Независимый обзор изменений относительно `4ae262d`: важные замечания закрыты.

Локальные протоколы и снимки: `docs/audits/2026-09-30-redesign/`, исключены из Git.
Это проверка редакции, а не пользовательское одобрение дизайна. На узком экране
язык и тема оставлены видимыми по замечаниям владельца; список активов требует
прокрутки. Дополнительные языки ожидают его списка. Экранный диктор, физическая
клавиатура телефона и испытания с пользователями не проводились.

Результаты прежнего полного аудита в [prototype-readiness.md](prototype-readiness.md)
относятся к прежней версии; их нельзя автоматически приписывать этой редакции.
