## Покрытие интерфейса

Три независимые линзы — визуальный дизайн, понятность сценариев и доступность —
проверили план и построенный интерфейс; находки сведены в один итог.

| Требования | Наблюдённая область статического интерфейса                                                                                           |

| R01–R03    | Семь адресов, Назад/Вперёд, «Ещё», фокус; RU/EN, RUB/USD, плотность, скрытие; один/все/набор/группа портфелей                         |
| R04–R06    | Формы портфелей/счетов/групп, 10 типов операций, поиск и фильтры, подробности/правка/удаление примеров                                |
| R07–R09    | Разложение результата выборки, активы/деньги/каталог, история/график/оценка, состав/отчёт/экспорт-пример                              |
| R10–R14    | Шаги импорта, ошибки/повторы/история/сверка, черновик/отмена, подключения, синхронизация, семь семейств настроек                      |
| R15–R18    | Помощь, статические состояния, формы и повторная обратная связь; RU/EN на 375/1440, 320 px и настоящий zoom 200% в измеренной области |
| R19–R21    | Строгий код, простая структура, лицензии и локальные workflow-проверки; переносимый навык                                             |

В единственном финальном обзоре закрыты гонка фокуса/прокрутки, неверная локаль
названий счетов, устаревшая область документов, осиротевшие стили, схема OpenSpec
и неполные доказательства браузерного прохода. Проверены назначения каталогов,
импорты и строковые пути. Все архивные изображения лично не пересматривались;
каждая внешняя исследовательская ссылка повторно не открывалась. Рекомендации
по иерархии редких действий и сокращению пояснений остаются необязательными.

## Навык product-readiness

[Пакет](../../skills/product-readiness/SKILL.md) содержит условные маршруты,
а не обязательную загрузку всех навыков. Пять контролей без навыка, пять первых
ответов с ним и пять после уточнения прочитаны вручную; отдельно проверены
недоступный браузер, дубликат/полномочия, отсутствие UI и недоступные источники.
Контроль уже сохранял полный бриф и UNKNOWN; улучшение по этим свойствам не
приписывается навыку. После уточнения 5/5 ответов сохранили явные поля файлов,
трёх UI-линз/консолидации, зависимостей и одного финального обзора.

Валидатор и установка в Codex/Claude Code проверены локально. Один фактический
вызов `/product-readiness` в Claude Code 2.1.285 завершился кодом 0 на условном
консольном преобразователе: UI=N/A, невыполненные проверки не PASS, обзор один.
Это не полный аудит MultiTracker в Claude Code и не доказательство надёжности
во всех случаях.

## Ограничения и воспроизведение

- Все данные вымышлены; сохранение не меняет финансовые примеры. Нет настоящих
  файлов, ключей, API, сервера, базы, хранения, шифрования и синхронизации.
- Разложение 86 420 RUB / 74 USD проверяет три учебные покупки; это не готовая
  методика доходности инвестора. Другие операции показывают формы, не движок учёта.
- Настоящий экранный диктор, системная мобильная клавиатура и испытания людей
  разных возрастов не проводились. Экспертная оценка не заменяет их.
- GitHub Actions и защита ветки подтверждены только в описанной выше области.
  Размещение приложения не проводилось; [ручной workflow Pages](../../.github/workflows/pages.yml)
  подготовлен для отдельного запуска.
- Сырые журналы, снимки, контрольные суммы и старые неуспешные попытки сохраняются
  локально в `docs/audits/` и `docs/evidence/`; они исключены из публичного Git.
  Это резюме не публикует сведения о частной среде и не заменяет исходные доказательства.

Для воспроизведения используйте [README](../../README.md): Node из `.nvmrc`,
`npm ci`, `npm run check`, затем отдельный `npm run test:ui` с запущенным сервером.
Полная матрица интерфейса шире автоматической цепочки. Изменения после указанного
кандидата требуют повторных затронутых проверок; результаты будущих GitHub run
добавляются только с фактической ссылкой и итогом.
