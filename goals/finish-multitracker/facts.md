# Факты

1. Макет содержит ровно семь разделов: Обзор, Портфели, Операции, Импорт, Подключения, Синхронизация, Настройки; нижняя панель телефона: Обзор, Портфели, Операции, Ещё.
2. В обзоре у строк RUB и USD карандаш «Изменить остаток» стоит в конце строки, высота строк равна остальным строкам активов.
3. Подпись «Откуда взялся результат · RUB» не переносится на вторую строку на ширинах 320, 375, 768 и 1440.
4. Сообщение «Отменить» не сдвигает список больше чем на 2 px; нажатие возвращает тот же элемент.
5. Пустая форма показывает короткую ошибку у каждого поля (количество, цена, сумма, комиссия), без длинной общей фразы и без слова «учебное»; «Получатель должен отличаться от источника» не показывается на пустой форме.
6. Кнопки «Удалить», «Отключить», «Отозвать доступ» оформлены как видимые действия строки 44×44 px с именем предмета; «⋯» и действий только по наведению нет.
7. При скрытых суммах результат, строки активов и причины результата нейтральны: нет классов positive/negative, стрелок и цветового знака.
8. После «Удаление данных» фокус остаётся на кнопке-открывателе (как в DESIGN.md); подтверждение требуется только у этого действия.
9. Полный перебор кликов пишет журнал JSONL: подпись элемента, действие, сдвиги, ошибки консоли; реестр незатронутых элементов не растёт (храповик).
10. Полный перебор измеряет покрытие кода (V8 и карты исходников) и долю нажатых элементов DOM по разделам; пороги записаны и не снижаются.
11. Перебор покрывает пары осей: язык, тема, валюта показа и расчёта, скрытие сумм, плотность, монохром, ширины 320/375/768/1440; формы десяти типов операций проверены на классах значений.
12. Ревью дизайна идёт при каждом клике: контраст, цель 44 px, перенос текста, сдвиг, переполнение, токены из DESIGN.md; любой видимый дефект блокирует PASS.
13. Все клавиатурные проверки и перебор выполняются в Linux-контейнере multitracker-layout-runtime; `npm run test:ui:docker` проходит без FAIL и NOT VERIFIED.
14. Правила репозитория: TS7 для tsc и TS6 для typescript-eslint (если совместимы, иначе ADR), прежние пороги 300/50/10 (те же единицы) не ослаблены, для нового кода действуют 250/25/8 (строк в файле, строк в функции, ветвлений); eslint, oxlint, tsconfig и gitleaks не ослаблены, подавлений и пропущенных тестов нет.
15. ADR фиксирует профиль F+P1 и таблицу adopt/optional/reject (Knip, dependency-cruiser и другие) по эталону v2.
16. `npm run check` завершается с кодом 0, DESIGN.md проходит lint без ошибок, русские тексты прошли ru-check и logika.
17. Итоговый коммит прошёл независимое ревью другой моделью, не автором правок, и зелёный CI на этом SHA (хеше коммита); ветка отправлена в GitHub без слияния в main.
