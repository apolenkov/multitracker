# План: доделать макет MultiTracker

Основание: [facts.md](facts.md), записка `docs/audits/2026-10-01-claude-crawl-final/HANDOFF.md`.
Исполнение: Devin через `devin-runner`, затем Pi при `RATE_LIMIT`, строго по одному.
Решения и приёмка: координатор Claude; второе мнение: Fable.

## Подход

Сначала правки известных дефектов, потом полный перебор кликов на исправленном макете,
затем ужесточение правил, затем независимое ревью и CI. Порядок важен: перебор на
сломанном макете даёт шум, а ужесточение правил до правок ломает сборку.

## Шаги

1. **Правки дефектов 1–5** (факты 2–8). Рабочая копия `.claude/worktrees/devin-wave`
   (ветка `devin/ui-wave` от `e481428`). Затрагивает `src/` обзора, строк действий,
   сообщений отмены, тексты ошибок в `src/i18n.ts` (файла `src/forms/messages.ts` на `e481428` нет; он только в WIP `d9a6b93`, не создавать). Проверка: `npm run check`,
   `npm run test:ui:docker`; добавить пробу сдвига при «Отменить» ≤ 2 px и ширины 320/768 в
   `scripts/ui-row-action-checks.ts` (иначе замер ручной по снимкам, без PASS автоматики).
2. **Слияние и перебазирование.** Слить `devin/ui-wave` в `fix/prototype-design`
   (fast-forward), перебазировать `devin/ui-exhaust`. Проверка: `npm run check`, `git log`.
3. **Достройка полного перебора**, `devin-exhaust`, два последовательных задания
   (прошлый запуск упал в лимит на полпути). (а) Покрытие кода и DOM, журнал JSONL,
   реестр незатронутых элементов с храповиком. (б) Пары осей, формы десяти типов,
   ревью дизайна на лету, отчёт; слой 4.3 «ревью через ИИ» заменить на последовательные
   запуски одного исполнителя. Проверка: прогон в контейнере до 30 минут, отчёт
   с покрытием, `tests/exhaust-core.test.ts`, ни одного FAIL.
4. **Правки по итогам перебора.** Один запуск Devin на найденные дефекты, повторный
   перебор; не больше двух итераций, дальше правки делает координатор. Пороги покрытия записать в конфиг, не снижать.
5. **Эталон v2, профиль F+P1.** TS7 для `tsc`, TS6 как алиас для typescript-eslint
   (при несовместимости оставить TS6, записать в ADR); `erasableSyntaxOnly` уже включён.
   Замер: пороги 250/25/8 дают на текущем дереве 1037/97/37 нарушений, поэтому прежние
   300/50/10 остаются, а новые пороги вводятся override-ом только для нового кода
   (`scripts/exhaust/**`, `tests/exhaust-core.test.ts`); цель и разрыв записать в ADR вместе
   с таблицей adopt/optional/reject. Механическое дробление функций ради порога не делаем.
   Проверка: `npm run check`; `git diff` конфигураций не содержит ослаблений.
6. **Тексты и документы** (факт 16). DESIGN.md, `docs/design/current-style.md`, README,
   ADR. DESIGN.md и факты согласовать (фокус после «Удаление данных» — на открывателе). Проверка: `npx @google/design.md lint` (версию закрепить, 0.4.0), `ru-check`, `logika`.
7. **Независимое ревью итогового SHA** (факт 17). Ревьюер не должен быть автором правок
   итогового SHA: если правки делал Pi, ревью делает Fable (субагент). Находки проверяет
   отдельный агент. Ревью и зелёный CI должны быть на одном и том же SHA: любая правка
   после ревью возвращает к этому шагу.
8. **CI.** Ветка `origin/fix/prototype-design` уже существует (fast-forward, 6 коммитов).
   Разрешение: ответ владельца «Делай как рекомендуешь» на вопрос об отправке ветки без
   слияния в main (2026-10-01). Отправлять после шага 2 и после шага 5 для раннего сигнала
   (CI идёт на Ubuntu с системным Chrome, не в контейнере); итоговый зелёный CI — на финальном SHA.
9. **Закрытие.** Запись в бэклог (TASK-060.15), ретроспектива, уборка хвостов
   (сервер 5177, контейнеры `multitracker-cash-*`, рабочие копии), просьба выключить отладку 9222.

## Риски и открытые вопросы

- Лимиты Devin и Pi: файла `~/.local/state/executor-limits` нет; при `RATE_LIMIT` — Pi,
  при обоих — ждать окно или делать самому.
- TS7 может не совместиться с typescript-eslint; тогда оставить TS6 и записать ADR.
- Порог ≤ 25 строк на функцию может потребовать правок в `scripts/exhaust/*`; без ослаблений.
- CI в GitHub Actions может расходиться с локальным контейнером; разбирать по журналу задания.
- Визуальную приёмку делает владелец, её не выдумываю.
