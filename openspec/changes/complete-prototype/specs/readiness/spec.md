# Требования готовности полного макета

Источники: исходный запрос пользователя, DESIGN.md, подтверждение полного макета,
аудит 2026-09-30. Суженный план первого этапа не отменяет эти требования.

## ADDED Requirements

### Requirement: R01 — Семь разделов, прямой адрес, Назад/Вперёд, мобильное Ещё

Макет и его репозиторий MUST обеспечивать следующий результат: Нужный экран и фокус main; настройки сохраняются.

#### Scenario: Проверка R01

- **GIVEN** согласованная статическая область и вымышленные данные, без настоящих интеграций
- **WHEN** пользователь открывает прямой адрес, переходит по разделам и использует Назад/Вперёд
- **THEN** Нужный экран и фокус main; настройки сохраняются

### Requirement: R02 — RU/EN, RUB/USD, скрытие сумм, плотность

Макет и его репозиторий MUST обеспечивать следующий результат: Перевод и формат всех сценариев; скрытие в деталях/отчёте.

#### Scenario: Проверка R02

- **GIVEN** согласованная статическая область и вымышленные данные, без настоящих интеграций
- **WHEN** пользователь переключает язык, валюту, видимость сумм и плотность
- **THEN** Перевод и формат всех сценариев; скрытие в деталях/отчёте

## Границы

Фиксированные суммы и данные; временные поля не сохраняют операции. Нет настоящих
файлов, ключей, API, криптографии, сервера, базы и фоновых очередей. Финансовая модель
содержит учебные покупки; дополнительные типы демонстрируют формы, а не расчётный движок.
Нулевые доходы и закрытый результат подписаны для данного учебного сценария.

Watchlist, ценовые уведомления, сложные сравнения и налоговые отчёты можно показать как
отдельные рекомендации будущего интерфейса, но они не подменяют обязательные R01–R21.
Торговля, новости и социальные функции не входят в задачу.

Экспертная проверка доступности не равна исследованию людей разных возрастов.
GitHub run, настоящий экранный диктор и фактическая работа навыка в Claude Code
считаются проверенными только после соответствующего запуска.
